# Brandyce Website

Official website for **Brandyce** — a Bangalore-based digital marketing and video-first branding company helping businesses build powerful brand identities, create impactful content, and drive measurable growth.

🌐 **Live site:** [www.brandyce.in](https://www.brandyce.in)

---

## About Brandyce

Brandyce partners with startups and growing businesses to craft brand identities that resonate. The focus is on video-first branding, high-converting social media management, CRM solutions, and AI-powered marketing strategies.

## Tech Stack

- **HTML5** — semantic markup across all pages
- **CSS3** (`styles.css`) — custom styling with CSS variables, glassmorphism effects, and responsive layout
- **Vanilla JavaScript** (`script.js`) — mobile menu, scroll animations, and interactive UI
- **Font Awesome 6** — icons
- **GitHub Pages** — hosting via custom domain

## Running Locally

No build step required — it's a static site.

1. Clone the repo:
   ```bash
   git clone https://github.com/chirag-s8/Brandyce-Website.git
   cd Brandyce-Website
   ```

2. Open `index.html` in your browser, or use a local server:
   ```bash
   # Using VS Code Live Server extension, or:
   npx serve .
   ```

---

## Deployment

The site is deployed via **GitHub Pages** with a custom domain configured in the `CNAME` file pointing to `www.brandyce.in`.

Any push to the `main` branch automatically updates the live site.
